# Video Generation Guide for Claude Code

This guide provides comprehensive specifications for creating JSON-formatted prompts for VIDEO nodes (when implemented). All VIDEO node prompts must be JSON strings with detailed video specifications.

## JSON Prompt Structure

When creating a VIDEO node, the `prompt` field must be a JSON string containing all video specifications. The JSON structure should follow this format:

  "inputVariable": "{{$json.content}}",

## Usage Notes for Claude Code

1. **Always use JSON format**: The `prompt` field in VIDEO nodes must be a JSON string

2. **Template variables**: Use Handlebars syntax {{$json.variableName}} or {{context.field}} within JSON string values

3. **Shot lists**: For multi-scene videos, include a detailed shot_list in generation_parameters

4. **Maintain consistency**: When creating multiple video segments (e.g., video series), keep the same technical specs and color grading across all segments

5. **Duration**: Specify duration_seconds in metadata - this helps determine pacing and content amount

6. **Audio considerations**: Consider whether music, voiceover, or sound effects are needed based on video type

## Example: Short Social Media Video Prompt

```json
{
  "context": "You are an expert social media video creator",
  "inputVariable": "{{$json.content}}",
  "metadata": {
    "video_type": "social media",
    "duration_seconds": 15,
    "primary_purpose": "marketing"
  },
  "camera": {
    "angles": ["medium shot"],
    "movement": "static",
    "framing": "rule of thirds"
  },
  "lighting": {
    "setup": "key light",
    "quality": "soft light",
    "intensity": "bright"
  },
  "color_grading": {
    "look": "vibrant",
    "contrast": "high",
    "saturation": "highly saturated"
  },
  "movement": {
    "subject_movement": "smooth",
    "camera_movement": "static"
  },
  "transitions": {
    "type": "cut",
    "style": "smooth"
  },
  "audio": {
    "music": {
      "present": true,
      "style": "upbeat",
      "volume": "background"
    }
  },
  "generation_parameters": {
    "prompt": "Create a vibrant 15-second social media video showing: {{content.main_message}}",
    "keywords": ["social media", "vibrant", "engaging", "modern"]
  }
}
```
