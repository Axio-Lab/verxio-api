# Ready-Made AI Design Prompts for Flyers, Instagram, Ads, Landing Pages & Business Branding

**CRITICAL: JSON Format Requirement**

All prompts in this guide MUST be converted to JSON format following the structure defined in image-generation-guide.txt. 

**Required JSON Structure:**
- `context`: Designer role and purpose
- `metadata`: Image type and primary purpose
- `composition`: Aspect ratio, layout, focal points, visual hierarchy, balance
- `color_profile`: Dominant colors, palette, temperature, saturation, contrast
- `lighting`: Type, quality, mood (for photorealistic assets)
- `technical_specs`: Medium, style, texture, sharpness
- `artistic_elements`: Genre, mood, visual style
- `typography`: Font details, placement, integration (when text is present)
- `generation_parameters`: The actual prompt text and keywords

**Brand Consistency Rule:**
When creating multiple assets for the same brand, establish brand foundation FIRST, then maintain EXACT same color_profile, technical_specs, and typography across all assets. Only vary the generation_parameters.prompt content.

Each section below shows:
1. **Natural Language Intent** - The design goal in plain language
2. **JSON Format Example** - How to structure it as JSON for DESIGN/DESIGN_PRO nodes

## BRAND FOUNDATION PROMPT (USE FIRST)

Use this once to lock in visual consistency across all assets. Convert to JSON format when creating DESIGN nodes.

**Natural Language Intent:**
Establish a consistent visual brand identity for a business.

Brand name: [Brand Name]
Industry: [Industry]
Target audience: [Audience]
Brand personality: [modern / luxury / bold / friendly / minimalist / playful]
Primary colors: [colors]
Secondary colors: [colors]
Typography style: [clean sans-serif / elegant serif / bold display]
Overall vibe: [emotional tone]

Apply this identity consistently to all future visuals.

**JSON Format Example:**
```json
{
  "context": "You are an expert brand designer establishing a visual identity",
  "metadata": {
    "image_type": "graphic design",
    "primary_purpose": "marketing"
  },
  "composition": {
    "aspect_ratio": "1:1",
    "layout": "single subject",
    "visual_hierarchy": "Brand elements clearly organized"
  },
  "color_profile": {
    "dominant_colors": [
      {"color": "[Primary Color]", "hex": "#XXXXXX", "percentage": "60%", "role": "primary"},
      {"color": "[Secondary Color]", "hex": "#XXXXXX", "percentage": "30%", "role": "accent"}
    ],
    "color_palette": "complementary",
    "temperature": "warm/cool/neutral",
    "saturation": "moderate",
    "contrast": "high contrast"
  },
  "technical_specs": {
    "medium": "digital",
    "style": "[minimalist/modern/luxury based on personality]",
    "texture": "smooth",
    "sharpness": "tack sharp"
  },
  "typography": {
    "present": true,
    "fonts": [{
      "type": "[sans-serif/serif/display based on style]",
      "weight": "bold",
      "characteristics": "[modern/elegant/bold based on personality]"
    }],
    "placement": "integrated",
    "integration": "prominent"
  },
  "generation_parameters": {
    "prompt": "Create a brand identity visual for [Brand Name] in the [Industry] industry targeting [Audience]. Brand personality: [personality]. Use primary color [color] and secondary color [color]. Typography style: [style]. Overall vibe: [tone]. This will serve as the foundation for all future branded assets.",
    "keywords": ["brand identity", "consistent", "[personality]", "[industry]"]
  }
}
```
