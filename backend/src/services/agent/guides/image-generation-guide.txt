# Image Generation Guide for Claude Code

This guide provides comprehensive specifications for creating JSON-formatted prompts for DESIGN nodes. All DESIGN node prompts must be JSON strings with detailed image specifications.

## Reference Images (DESIGN_PRO Only)

DESIGN_PRO nodes support up to 14 reference images for advanced editing:
- **Object images**: Up to 6 images of objects to include in the final image
- **Human images**: Up to 5 images of humans to maintain character consistency
- **Total maximum**: 14 reference images

**Specifying Reference Images in JSON:**
```json
{
  "referenceImages": [
    {
      "image": "{{design1.imageUrl}}",
      "type": "object"
    },
    {
      "image": "base64...",
      "mimeType": "image/jpeg",
      "type": "human"
    }
  ]
}
```

**Image Sources:**
- Previous node outputs: Use Handlebars templates like `{{design1.imageUrl}}`
- URLs: Direct image URLs (will be fetched automatically)
- Base64: Raw base64 encoded strings

## Editing Modes (DESIGN_PRO)

DESIGN_PRO supports multiple modes:

### Generate Mode
- Same as DESIGN node - text-to-image generation
- Use for: Creating new images from scratch

### Edit Mode
- Edit an existing image with text prompts
- Requires: `sourceImage` field (URL, base64, or {{previousNode.imageUrl}})
- Use for: Single edits like "change text to Spanish", "add a logo", "adjust colors"

### Chat Mode
- Multi-turn conversational editing
- Maintains conversation history for iterative improvements
- Use for: Complex editing workflows where user wants to refine images through conversation
- Example workflow:
  1. First DESIGN_PRO (generate): Create initial image
  2. Second DESIGN_PRO (chat): "Change the text to Spanish"
  3. Third DESIGN_PRO (chat): "Make the background darker"
  4. Each turn builds on previous conversation

### Edit With References Mode
- Edit with reference images (up to 14)
- Use for: Creating composite images, maintaining character consistency, mixing multiple elements
- Example: "Create a group photo of these people making funny faces" with 5 reference human images

## Usage Notes for Claude Code

1. **Always use JSON format**: The `prompt` field in DESIGN/DESIGN_PRO nodes must be a JSON string (use JSON.stringify() or similar)

2. **Template variables**: Use Handlebars syntax {{$json.variableName}} or {{context.field}} within JSON string values

3. **Required vs Optional**: Include all relevant sections, but omit sections that don't apply to the image type

4. **Maintain consistency**: When creating multiple images (e.g., presentation slides), keep the same structure and styling parameters across all images, only varying content-specific fields

5. **Presentation slides**: For slide generation, use aspect_ratio "16:9" and consider using "presentation_slide" template

6. **Content extraction**: When user provides content, extract relevant sections and create appropriate prompts for each slide/image

7. **Choosing DESIGN vs DESIGN_PRO**:
   - Use DESIGN for simple text-to-image generation
   - Use DESIGN_PRO for: editing existing images, multi-turn conversations, reference images, high-res output (1K/2K/4K), Google Search grounding

8. **Multi-turn editing**: For iterative improvements, use DESIGN_PRO in chat mode. Chain multiple DESIGN_PRO nodes, each in chat mode, to build on previous edits

## Example: Presentation Slide Prompt

```json
{
  "context": "You are an expert presentation designer creating professional slides",
  "inputVariable": "{{$json.slideContent}}",
  "metadata": {
    "image_type": "graphic design",
    "primary_purpose": "marketing"
  },
  "composition": {
    "aspect_ratio": "16:9",
    "layout": "single subject",
    "visual_hierarchy": "Title at top, content in center, supporting elements balanced"
  },
  "color_profile": {
    "temperature": "cool",
    "saturation": "moderate",
    "contrast": "medium contrast"
  },
  "technical_specs": {
    "medium": "digital",
    "style": "minimalist",
    "texture": "smooth",
    "sharpness": "tack sharp"
  },
  "typography": {
    "present": true,
    "fonts": [
      {
        "type": "sans-serif",
        "weight": "bold",
        "characteristics": "modern"
      }
    ],
    "placement": "overlay",
    "integration": "prominent"
  },
  "generation_parameters": {
    "prompt": "Create a professional presentation slide with: {{slideContent.title}} as the main heading and {{slideContent.body}} as supporting text. Use clean, modern design with ample white space.",
    "keywords": ["professional", "modern", "clean", "presentation", "slide"]
  }
}
```
